# Site Mariage Laura & Mathieu — V2

Cette version utilise la photo originale fournie, sans retouche.

## Structure
- Accueil
- Programme
- Mention week-end entre adultes
- Hébergements
- Navettes
- RSVP individuel avant le 31 mars 2027

## RSVP
Chaque invité répond individuellement, même en couple.
Champs :
- prénom
- nom
- e-mail
- présence jeudi
- présence vendredi
- allergies / régime
- hébergement réservé ou non
- nom de l'hébergement
- besoin de navette

## Tester sur Mac
1. Décompresser le ZIP.
2. Ouvrir le dossier.
3. Double-cliquer sur `index.html`.
4. Le site s’ouvrira dans Safari ou Chrome.

## Important
Le formulaire est en mode démo tant que `GOOGLE_SCRIPT_URL` est vide.
Les réponses de test sont enregistrées seulement dans le navigateur.

## Étape suivante
On connectera le RSVP à un Google Sheet gratuit avec `Code.gs`, puis on publiera le site gratuitement sur GitHub Pages ou Cloudflare Pages.
